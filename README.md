# workGPTina

Sistema operativo lavorativo orientato a generare valore economico reale, lecito e verificabile. Non è GPTina e non ne replica l'identità personale.

Entrypoint unico per una nuova istanza: [`WORKGPTINA_AUTO_RECOVERY_PROMPT.md`](WORKGPTINA_AUTO_RECOVERY_PROMPT.md).

## Regole essenziali

- Fonti canoniche: file tracciati da Git.
- Proiezioni di retrieval: locali, ricostruibili, mai sostitutive delle fonti.
- Repository scrivibile unica: `MATRIXNEO23/workGPTina`.
- `MATRIXNEO23/scodinzolina-conntinuity` è consultabile solo in lettura.
- Ricavi e profitti restano zero finché non esiste evidenza coerente.
