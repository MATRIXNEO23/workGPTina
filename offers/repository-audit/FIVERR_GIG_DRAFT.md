Is your repository difficult to resume because branches, artifacts, CI failures, and documentation no longer tell one consistent story?

I will perform a scoped, evidence-based repository audit and show you:

- what is complete, partial, missing, contradicted, or unknown;

## FAQ

### Can you recover deleted files or missing artifacts?
I can inspect available Git history, releases, workflow artifacts, and documented sources. I cannot promise recovery of data that no longer exists.

### Will you modify my repository?
Basic is read-only. Standard and Premium include only the limited fixes stated in the package, after explicit authorization.

### Do you need my password or token?
No. Never send credentials in chat or commit them to the repository. Use the minimum platform-supported access required.

### Do you guarantee a green build?
No false guarantees. I guarantee a verified report and reproducible findings within scope. A fix is delivered only when supported and testable.

### What counts as one fix?
One bounded root cause affecting a workflow, recovery pointer, configuration, or handoff—not a general refactor or new feature.
