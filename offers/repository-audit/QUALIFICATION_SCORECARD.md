# Qualification scorecard — Audit Recovery & CI

Usare prima di includere un possibile cliente nel campione. Non raccogliere dati personali non necessari.

## Requisiti minimi

- repository indicata dal potenziale cliente o problema dichiarato pubblicamente;
- problema coerente con recovery, CI, stato artefatti o handoff;
- proprietario o referente identificabile senza scraping invasivo;
- canale che consente legittimamente il contatto;
- nessuna richiesta illegale, elusione di accessi o uso di credenziali altrui.

## Punteggio 0–2

| Fattore | 0 | 1 | 2 |
|---|---|---|---|
| Dolore osservabile | vago | probabile | esplicito |
| Urgenza | assente | moderata | build/release bloccata |
| Fit tecnico | basso | parziale | diretto |
| Accessibilità | nessun canale | canale freddo | richiesta/contatto consentito |
| Capacità di pagare | ignota/improbabile | possibile | budget o acquisti osservabili |
| Scope pilota | enorme | riducibile | già circoscritto |

Qualificare nel test soltanto con totale ≥8/12 e nessun requisito minimo fallito. Il punteggio non prova disponibilità a pagare.
